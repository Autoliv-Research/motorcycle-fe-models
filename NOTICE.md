# 1. About this Repository

This repository contains open-source powered two-wheeler (PTW) finite element simulation models developed by Autoliv for research, educational, and technical evaluation purposes. The repository primarily consists of LS-DYNA model files (.k files) and associated documentation necessary to understand and use the models. The materials made available through this repository are limited to the files expressly included in the repository. No other Autoliv technology, intellectual property, software, data, know-how, tools, methodologies, development assets, validation assets, or materials are provided or licensed.
The repository currently includes LS-DYNA finite element models of: 

- Yamaha YS125
- KTM 390
- Honda Super Cub
- Honda Gold Wing GL1800
