# Autoliv Open-Source PTW Finite Element Models

This repository contains powered two-wheeler finite element simulation models
developed by Autoliv for research, educational, and technical evaluation purposes.

The repository currently includes LS-DYNA finite element models of:
 
- Yamaha YS125
- KTM 390
- Honda Super Cub
- Honda Gold Wing GL1800

## How to use

After cloning the repository or downloading the zip-file corresponding to the model you are interested in, you can unzip the zip-file. In the extracted folder, you can find a file that  starts with "00_MAIN_XXX" which is the main model file.
